# Intended use

AOS is a local-first open assessment of how effectively a human operator runs AI coding agents in a declared environment. The allowed use is that conditional measurement, plus the verification commands documented on the public surface.

AOS is not a hiring, promotion, or surveillance instrument.

## Defaults

- Default telemetry is OFF.
- Secret values are never stored.
- Hidden chain-of-thought is never stored.
- Verified runs and reports stay local.
- Optional anonymous export is explicit, allowlisted, and implemented only by its owning ticket.

## Provenance

A score is produced by the deterministic scorer from an aos-trace under a declared Opportunity Profile. The Opportunity Profile, artifact digests, and scorer identity are the provenance of that number. The number is not a personal ability independent of environment.
