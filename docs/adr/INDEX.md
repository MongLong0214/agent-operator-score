# Architecture Decision Records

Status: **PROPOSED — derived from the final AOS SSOT; product implementation is blocked until explicit Maintainer approval of this ADR set.**

| ADR | Decision |
|---|---|
| [ADR-0001](ADR-0001-product-identity-and-legacy-boundary.md) | Freeze Agent Operator Score identity and isolate legacy names |
| [ADR-0002](ADR-0002-intended-use-scope-and-claims.md) | Limit AOS to local provisional coding-operator assessment |
| [ADR-0003](ADR-0003-runtime-repository-and-distribution.md) | Use strict TypeScript, Node.js, npm workspaces, and local CLI distribution |
| [ADR-0004](ADR-0004-construct-opportunity-and-comparison.md) | Bind every score to an Opportunity Profile without pretending to deconfound it |
| [ADR-0005](ADR-0005-metric-opportunity-and-issuance.md) | Freeze M01–M20, opportunity semantics, and score issuance requirements |
| [ADR-0006](ADR-0006-trace-result-and-deterministic-scoring.md) | Use versioned normalized traces, canonical results, and deterministic-first grading |
| [ADR-0007](ADR-0007-adapter-observability-and-session-class.md) | Declare adapter observability and separate controlled from imported sessions |
| [ADR-0008](ADR-0008-runner-isolation-privacy-and-integrity.md) | Isolate workspaces, workers, oracles, secrets, processes, and run state |
| [ADR-0009](ADR-0009-scenario-pack-forms-and-build-order.md) | Build the differentiated wedge before the full assessment pack |
| [ADR-0010](ADR-0010-prescription-and-retest-attribution.md) | Issue one deterministic lever and separate retest attribution |
| [ADR-0011](ADR-0011-validation-gates-and-pivot-rules.md) | Gate public claims on scorer truth, human signal, transfer, and open reproduction |
| [ADR-0012](ADR-0012-planning-tdd-and-exact-head-governance.md) | Require gated ADR, PRD, atomic ticket, TDD, cumulative review, and exact-head evidence |
