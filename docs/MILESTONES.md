# Milestones and evidence gates

No due dates are assigned. Calendar targets cannot override evidence gates.

| Milestone | Included epics | Exit gate |
|---|---|---|
| S0 · Name & Contracts | D0, E0-A, E0-B, E0-C, E0-D | Canonical identity and all measurement contracts are accepted and executable. |

| S3 · Full Form A & Second Runtime | E8–E10 | Six-family Form A passes timing/eligibility, Claude parity is explicit, and canonical report/lever pass. |
| S4 · Human Alpha & Retest | E11–E12 | Preregistered alpha yields honest G1/G2/G3 PASS/FAIL/INCONCLUSIVE verdicts. |
| S5 · Public OSS | E13–E14 | Snapshot contract, name/license/security, independent reproduction, and G4 pass before any public release. |

## Stop rule

If a milestone exit gate fails, later milestones remain blocked. The allowed response is repair within the owning contract or execute the SSOT pivot; never relax the gate silently.
